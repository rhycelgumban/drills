## 📖 Contents

### 🔹 Barangay Visitor Log

A Python program that records visitors entering the barangay hall. The program stores visitor information, displays all recorded visitors, and shows the total number of visitors.

### 🔹 Library Book Borrowing System

A menu-driven Python application that manages library books. Users can:

- View all books
- Borrow a book
- Return a book
- View available books
- View borrowed books

The project separates the data (`models.py`) from the program logic (`views.py`) to demonstrate basic program organization.

## 🚀 Running a Program

Open a terminal inside the project folder and run:

```bash
python main.py
```

or

```bash
py main.py
```
